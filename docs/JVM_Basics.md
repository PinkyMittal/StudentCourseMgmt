JDK : It is Java Developement Kit. Its Everything which developer needs to develop and run for program.
It Contains JRE,JVM,Compiler and debugging tools.

JRE : It is something which is required to run the program.It contains JVM , library and supporting files.

JVM : Its an engine that runs java program.It contains byte code, Manage Memory,Handle Garbage Collection.
      The code run through JVM are platform independent. 

ByteCode : It is a class file which is generated by JVM and is not human readable.

WORA : It means Write Once Run Anywhere. This means the bytecode generated by JVM are platform independent. Its generate a class file which can be taken and can run in any machine with the help of machine specific JVM.
